# external-repo-federation
Use config/external_repo_federation.json as the source registry. Classify every upstream capability as TOOLCHAIN_ONLY, REFERENCE_ONLY, or SANDBOX_ONLY before use. Pin the source commit. Inspect license, dependencies, security posture, secrets handling, and runtime assumptions. Prefer adaptation into AURELIA-owned code over vendoring. Do not import external broker execution, credentials, trading engines, or authority. Record evidence before promotion.
