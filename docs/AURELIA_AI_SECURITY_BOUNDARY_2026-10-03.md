# AURELIA AI Security Boundary — 2026-10-03

AI systems may research, analyze, propose decisions, generate candidate code, and explain evidence. They may not grant capital authority, change the live lock, replace the execution adapter, bypass Risk Warden, bypass Execution Firewall, bypass reconciliation, or resubmit an ambiguous transaction.

AI-generated changes reach production only through reviewed source, tests, security checks, approved configuration, immutable deployment provenance, and an explicit release transition.
