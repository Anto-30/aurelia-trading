# AURELIA Dual-Primary Brain Architecture

ChatGPT and Claude Code are peer primary intelligence brains. Neither is a capital authority.

ChatGPT handles system planning, decomposition, research synthesis, market context and cross-agent coordination. Claude Code handles engineering, implementation, CI/CD, deployment diagnostics and code repair. Both can delegate through the persistent AURELIA federation.

For high-consequence or capital-relevant work, both verified primary brains are required before the existing deterministic AURELIA validation chain. Missing provider authentication causes abstention rather than fabricated results.

AURELIA remains sovereign for LIVE_LOCK, Risk Warden, Execution Firewall, Account Isolation, probability validation, strategy qualification, transaction verification, reconciliation, idempotency, kill-switch behavior and final execution authorization.
