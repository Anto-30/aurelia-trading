# AURELIA Dual-Primary Brain Architecture

ChatGPT and Claude Code are the two primary intelligence brains. They are peers and interchangeable at the intelligence layer; neither is a capital authority.

ChatGPT handles system-level planning, decomposition, research synthesis, market context and cross-agent coordination. Claude Code handles engineering, implementation, CI/CD, deployment diagnostics and code-level repair. Either can delegate to every registered specialist through the persistent AURELIA federation.

For high-consequence or capital-relevant work, both primary brains must be verified and independently consulted. Their outputs remain advisory evidence and are passed through the existing deterministic AURELIA validation chain.

AURELIA remains sovereign for LIVE_LOCK, Risk Warden, Execution Firewall, Account Isolation, probability validation, strategy qualification, transaction verification, reconciliation, idempotency, kill-switch behavior and final execution authorization.

Provider configuration is not proof of authentication. Missing provider authentication produces an intelligence-plane abstention rather than a fabricated heartbeat or model result.

The OpenAI side should use the current Responses API; OpenAI states that the Assistants API was sunset on August 26, 2026. See the official migration documentation: https://platform.openai.com/docs/assistants/migration.

No Deriv credential, API key, token, OTP, authenticated URL or other secret belongs in this repository or in model prompts.
