## Rechecked integration decision

1. **No external repo is promoted into AURELIA.** Keep the canonical capital plane and deterministic risk/release authority inside AURELIA.
2. **XERJ is blocked pending dependency remediation.** Upstream CI's cargo-audit failure is concrete evidence, and the affected lockfile is unchanged at current HEAD. Do not deploy it or index sensitive material until a fixed lockfile is audited and the complete CI/security suite passes.
3. **SIE is not safe to expose with defaults.** If tested later, use a disposable environment, loopback-only port binding, token auth, no sensitive corpus, resource limits, and model-license review.
4. **Pi remains the leading research-agent harness candidate only if sandboxed externally.** Its own policy explicitly does not promise a sandbox.
5. **Technical indicators remain test-only.** Establish independent fixtures and parity before any code adoption.
6. **All OpenBot and plugin systems remain untrusted by default.** Restrict tools, identity, filesystem, and network; pin code and review licenses. Do not give them broker credentials or order APIs.
7. **Arbitrage repositories are not evidence of a trading edge.** Require current data, execution-cost modeling, and out-of-sample results.
